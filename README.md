# Dokumentasi Sistem Informasi Perpustakaan Digital (E-Library)

Repository ini berisi kumpulan dokumentasi untuk pengembangan Sistem Informasi Perpustakaan Digital (E-Library). 

## Tujuan Sistem
Memudahkan pengelolaan sirkulasi buku, memungkinkan pencarian katalog secara daring, dan menyediakan akses e-book bagi anggota perpustakaan.

## Struktur Folder Dokumentasi
- **/Perencanaan**: Berisi dokumen proposal dan analisis kebutuhan.
- **/Desain**: Berisi dokumen perancangan database dan antarmuka (UI/UX).
- **/Manual**: Berisi panduan penggunaan sistem untuk admin dan anggota.
