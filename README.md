# Dokumentasi Sistem Informasi Perpustakaan
 
## Deskripsi
Repository ini berisi dokumentasi Sistem Informasi Perpustakaan (SIPUS) untuk mengelola koleksi, anggota, peminjaman, pengembalian, dan denda.
 
## Tujuan
Menyimpan dan mengelola dokumentasi sistem secara terpusat, terstruktur, dan mudah diakses menggunakan layanan cloud GitHub.

## Struktur Folder Dokumentasi
- **/Perencanaan**: Berisi dokumen proposal dan analisis kebutuhan.
- **/Desain**: Berisi dokumen perancangan database dan antarmuka (UI/UX).
- **/Manual**: Berisi panduan penggunaan sistem untuk admin dan anggota.

## Pengguna Sistem
Pustakawan/admin, anggota, dan pimpinan perpustakaan.
